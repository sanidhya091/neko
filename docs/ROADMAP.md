# Project Neko Roadmap

This roadmap outlines the planned development phases for **Project Neko**, evolving from a robust core engine into a thriving open-source desktop pet platform.

---

## 🗺️ Phase 1: Core Engine Foundation (Completed)
- [x] Electron transparent overlay window architecture
- [x] PixiJS WebGL rendering engine & sprite management
- [x] Finite State Machine (FSM) AI behavior engine
- [x] Personality & mood state systems
- [x] Original pixel-art cat (`Neko`) asset pipeline & animations

## 🗺️ Phase 2: Interactivity & Physics (Current)
- [ ] Cursor tracking and chasing mechanics
- [ ] Drag-and-drop pet physics and reactions
- [ ] Interactive click responses (purring, heart emotes)
- [ ] Sound effects integration (walking, meowing, sleeping)

## 🗺️ Phase 3: Ecosystem & Plugins (Planned)
- [ ] VS Code / Cursor IDE build status integration
- [ ] Spotify / media playback dancing integration
- [ ] Battery and weather monitoring plugins
- [ ] Community pet marketplace and mod loader UI

## 🗺️ Phase 4: Multi-Pet & Cross-Platform (Future)
- [ ] Multi-pet desktop companionship
- [ ] Native macOS and Linux window overlay optimizations
- [ ] WebAssembly community mod sandbox
